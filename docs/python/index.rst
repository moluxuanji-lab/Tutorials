Python 教程
============

.. meta::
   :summary: 面向中文开发者的 Python 结构化教程：从基础语法、数据结构到函数、类、标准库与网络应用。
   :group: 入门

本教程以菜鸟教程 Python 3 系列为基础，对照 Python 3.13 官方文档查漏补缺，按“入门 → 核心语法 → 进阶 → 标准库与实战”的学习路径组织，共 44 章。每一章都配有可以直接运行的示例，建议边读边在解释器或编辑器中动手实践。

.. note::

   阅读过程中可以随时按下 ``Ctrl + K`` 搜索函数或概念，代码块右上角支持一键复制。所有示例都在 Python 3.13 下实际运行验证过。
