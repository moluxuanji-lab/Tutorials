PowerShell 教程
===============

.. meta::
   :summary: 面向中文开发者的 PowerShell 结构化教程：从对象管道、Cmdlet 到模块化、错误处理与远程运维。
   :group: 入门

本教程以菜鸟教程 PowerShell 系列为基础，对照微软官方文档（PowerShell 7.6）查漏补缺，按“入门 → 核心概念 → 常用操作 → 工程化 → 进阶实战”的学习路径组织，共 24 章。每一章都配有可直接运行的命令示例，建议边读边在 PowerShell 控制台中动手实践。

.. note::

   阅读过程中可以随时按下 ``Ctrl + K`` 搜索命令或概念，代码块右上角支持一键复制。
